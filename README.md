# Automatic Door Opening System Using IR Sensor

## Project Overview
This project focuses on designing and implementing an Automatic Door Opening System using an IR (Infrared) sensor. The system detects the presence of a person near the door and automatically opens it, improving convenience and reducing manual effort.

## Objective
The main objective of this project is to:
- Develop an automatic door control system using IR sensors
- Reduce manual door operation
- Provide a low-cost and efficient solution using locally available materials

## Key Features
- Automatic door detection using IR sensor
- Hands-free door operation
- Energy efficient system
- Low cost implementation
- Simple and reliable design

## Components Used
- IR Sensor
- Microcontroller
- Motor / Servo Motor
- Power Supply
- Mechanical Door Setup

## Working Principle
1. The IR sensor detects the presence of a person.
2. The sensor sends a signal to the controller.
3. The controller activates the motor.
4. The door automatically opens and closes after a short delay.

## Advantages
- Reduces human effort
- Cost-effective solution
- Improves accessibility
- Easy to install and maintain

## Applications
- Shopping malls
- Hospitals
- Offices
- Smart homes
- Public buildings

## Outcome
The project successfully demonstrates an economical automatic door system that provides convenience, improves efficiency, and serves as a practical automation solution.
